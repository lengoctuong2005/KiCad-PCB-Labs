# HCMUT - Thiết Kế Mạch In PCB với KiCad (Khóa Hè)

Tập hợp toàn bộ các bài thực hành và đồ án thiết kế PCB (KiCad) trong khóa học Thiết kế Mạch In / Vi Mạch.

## 📂 Danh mục bài tập (Labs & Project)

- **Common_Libraries/**: Thư viện linh kiện Footprint và Symbol tự tạo dùng chung.
- **Lab1/**: Thiết kế Mạch Nguồn Cơ Bản (Schematic, PCB Layout, Báo cáo kỹ thuật).
- **Lab2/**: Mạch Khuếch Đại / Cảm Biến & Sắp xếp linh kiện tiêu chuẩn.
- **Lab3/**: Mạch Giao Tiếp & Chuyển Đổi Nguồn (Schematic, Routing 2 lớp, BOM, Báo cáo & Kiểm tra DRC/ERC).
- **Lab4/**: Mạch Vi Điều Khiển / Ngoại Vi Mở Rộng.
- **Lab5/**: Thiết Kế Mạch RF / Cao Tần & Layout Nâng Cao.
- **Lab6/**: Tổng Hợp Thiết Kế Hoàn Chỉnh & Xuất File Gia Công (Gerber, Drill, BOM, CPL).
- **DoAn/**: Tài liệu và danh mục đề tài Đồ Án Cuối Khóa.

## 🛠️ Công cụ sử dụng
- **KiCad EDA v8 / v9**
- Schematic Editor (`.kicad_sch`)
- PCB Editor (`.kicad_pcb`)
- Footprint & Symbol Libraries (`.kicad_mod`, `.kicad_sym`)
